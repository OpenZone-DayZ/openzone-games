# OpenZone Games, Phase 1: The Rules on the Stand — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the `openzone-games` repository and build the rules half of OpenZone Games with nothing in the world yet: cards, what a game is, the registry of games, and durak in both variants with save and load, played on the stand by script.

**Architecture:** One pbo, `OpenZone_Games`. The rules live in 3_Game and see nothing of the world: seats come to a game as numbers, chance is handed in, and what a game tells is text. A CF module in 4_World registers the games and prints the ready line. A server-only stand pbo, `OpenZone_Games_Bridge`, adds the verb `oz_games` to the MCP bridge: a bench that plays one game through the contract a session will use later, with the order of the deck fixed, and a fuzz that plays whole games by chance and checks the state after every move. The probe of 2026-11-23 moves into the repository as it is.

**Tech Stack:** Enforce Script on DayZ 1.30.164289 (diag build), Community Framework, `OpenZone_Core`, the `dayz` MCP server (`project_open`, `mod_lint`, `mod_build`, `server_start`, `log_verdict`, `world_ready`, `world_exec`, `client_compile_check`), Python 3 (the string table tool), git.

**Design:** `E:\openzone\docs\specs\2026-11-23-openzone-games-design.md` — §2 the mod, §3.1 a deck is 52 cards, §6.3 what a game waits for, §7 a game is a module, §8 durak, §9 what a save is for, §15 item 1 (the rules checked through `oz_games`). ## Decisions this plan makes where the design is silent

Each is the plan's own and can be changed by the owner; Task 7 writes them into the design.

1. **The contract's names differ a little from the table of design §7.** `GameId`, `CardsUsed`, `OptionList`, `IsOver`, `Outcome`, `SaveState`, `LoadState`, `DropSeat` stand for `Id`, `Cards`, `Options`, `Over`, `Result`, `Save`, `Load`, `Drop`: a method named like a class of another mod is compiled as that class's constructor, and those words are likely class names.
2. **`Begin` answers yes or no** and says why: a deal for fewer than `MinPlayers` or more than `MaxPlayers` seats is refused with `STR_OZG_NO_PLAYERS`.
3. **Four things the table of §7 does not list.** `Moves(seat)`: what the seat may play now, as wire moves; it rides in the seat's own half of a view as `CanPlay`, so the window lights cards without knowing the rules. `SkipSeat(seat)` and `SkipAbsent(seats)`: how a move that need not be made is passed over (§6.3). `Sound()`: the check behind §9's "does not add up". `Brief()` and `Everything()`: one line each for the log and the stand, the second with every hidden card and never sent to a client.
4. **The hint** handed to `Begin` is `key=value` pairs joined with `;`. A session will send `host=<seat>` and add what the game that ended said through `Outcome()`; durak says `durak=<seat>`, or `durak=-1` when there was none. Leaving the durak's part out when that player has left the seat is the session's business (phase 3).
5. **Dealing goes a seat at a time**, six cards to the first seat, six to the next, and what is left is the stock. For a shuffled deck it deals the same hands as card by card around the mat would, and a check can write a deck as hand, hand, stock.
6. **Six seats take the whole deck**, and then no card is left to turn up: the trump is the last card dealt, shown to everybody, and it stays in that hand. That hand holds it as its trump, also for "the lowest trump".
7. **`n` in `d:<card>:<n>` counts from 1.**
8. **A pass** is taken only from a seat that could still throw in, and it does not bar that seat from throwing in later in the same bout: it says "nothing from me for now", and any new card on the table, or the defender's "take", asks everybody again.
9. **Which refusal is said when several apply.** Throwing in: the defender, the card not held, the limit, the rank. Moving the attack on: not the defender, the variant, an empty table, too late, the next seat's cards, the card not held, the rank.
10. **Who is waited for.** The opener while the table is empty; the defender while a card lies unbeaten and "take" has not been said; and, once the bout could close, every seat that may still throw in and has not passed. Only the third kind may be passed over for a player who is not present.
11. **A dropped seat.** Everyone draws starting from the first seat after the dropped one. The limit of five stays until a bout of the game has closed in the ordinary way. A game that ends because a seat was dropped has no durak, whatever the hands were.
12. **Perevodnoy for two.** The attack moves back to the seat that opened it, which then defends. The opening seat keeps its place in the order of drawing: first, unless it is the one defending when the bout closes.
13. **The saved game keeps the discards as cards**, not as a count, so that `Sound` can find every one of the 36 exactly once.
14. **The registry is not emptied when a mission starts**: another mod's module may have registered its game first. Durak registers itself once; the registry is emptied when the mission ends.
15. **The stand's world stays instance 83**, the probe's; its config is renamed `serverDZ_games.cfg`. The probe moves in with its names as they are (`TableGamesProbe`, `TGP_`, the verb `tgp`) and stays among the project's mods, so that every build proves it still compiles beside the mod.
16. **The probe's four screenshots are kept as JPEG**: 17 MB of PNG would stay in the repository's history for ever.
17. **The bench never shuffles by real chance unless asked** (`seed=0`): an answer on the stand has to be the same tomorrow.
18. **The client's half is compiled once**, at the end (Task 6). Design §15 item 7 asks for the client compile check on every build; nothing in this phase is compiled for a client alone, and the check takes two minutes. From the phase that brings client-only code it belongs to the stand cycle.

### A game on the bench

Every row of this plan is one `mcp__dayz__world_exec(verb="oz_games", args={...})`; the row shows the `args` and then the `detail` that must come back, to the letter. Every value of `args` is a string.

- **A deck** is written as the cards in the order they are dealt: six for the first seat, six for the next, then the stock from its top; the last card of the 36 is the trump. Cards that are not named follow the named ones in the deck's own order (spades, hearts, diamonds, clubs, each from six to ace), so a deck that names only the hands ends with the ace of clubs, and clubs are trumps.
- **`begin`** deals. `seats` are the seats' numbers, `opt` the variant, `hint` what a session would carry from the last game. With neither `deck` nor `seed` the shuffle is the one of seed 1.
- **`act`** is one move and answers `ok` or `no <key>`, then the brief. **`play`** is several moves, `<seat> <move>` parted by `;`, and answers a mark for each (`+` taken, `-<key>` refused), then the brief after the last.
- **The brief** is one line: `durak <variant> trump=<card> stock=<cards> dis=<discards> table=<attack/beaten by, ...> op=<opener> def=<defender> lim=<attack cards allowed> take=<0|1> first=<first bout: 0|1> hands=<seat>:<cards>... waits=<seats>`. In `hands`, `x` marks a seat that is out, `d` a dropped one, `p` one that has passed. After the end it is `durak <variant> over <durak=<seat> | tie | nodurak> trump= stock= dis= hands=`.
- **`all`** shows every hand, the table and the stock; **`can seat=`** what a seat may play now and whether it is waited for; **`away seats=`** names the seats whose players are "not present" and passes over what they need not do, as a session will after every change (the answer then says `skipped=<n>`).
- **Several rows sent in one message** are carried out in the order sent, two seconds apart. The rows of one table may be sent together, each still checked against its own answer.
- **A row that answers differently is a finding.** Stop, read `all`, and decide whether the code or the expectation is wrong before going on: every later row of the table stands on this one.

```python
# Expands <mod>/strings.csv (key, Ukrainian, English) into the game's
# <mod>/stringtable.csv: fifteen columns, every field quoted, a comma after the
# last one, a BOM in front -- the shape the rest of the series ships. Ukrainian
# is the original and stands in every column but the English one.
#
# Usage: python -I tools/stringtable.py <path to the mod's folder>
import csv
import io
import os
import sys

COLUMNS = ["Language", "original", "english", "czech", "german", "russian", "polish",
           "hungarian", "italian", "spanish", "french", "chinese", "japanese",
           "portuguese", "chinesesimp"]

mod = sys.argv[1]
rows = []
with io.open(os.path.join(mod, "strings.csv"), encoding="utf-8-sig", newline="") as f:
    for line in csv.reader(f):
        if not line or line[0].startswith("#"):
            continue
        if len(line) != 3:
            raise SystemExit("strings.csv: three fields a line, got %r" % (line,))
        key, ukrainian, english = line
        row = [key, ukrainian, english] + [ukrainian] * (len(COLUMNS) - 3)
        rows.append(row)

keys = [r[0] for r in rows]
twice = sorted(set(k for k in keys if keys.count(k) > 1))
if twice:
    raise SystemExit("strings.csv: listed twice: %s" % ", ".join(twice))


def quoted(fields):
    return ",".join('"' + x.replace('"', '""') + '"' for x in fields) + ","


text = "\n".join([quoted(COLUMNS)] + [quoted(r) for r in rows]) + "\n"
with io.open(os.path.join(mod, "stringtable.csv"), "w", encoding="utf-8-sig", newline="\n") as f:
    f.write(text)
print("stringtable.csv: %d strings" % len(rows))
```

```c
// The mod's log lines.
//
// A prefix of its own: in a server log with thirty mods a line must say whose
// it is, and the stand's verdict looks for this prefix. WARNING and ERROR are
// written in full: the verdict counts the first as a whole word and matches
// `[OpenZone/Games] ERROR` (error_regex in dayz-mcp.toml).
//
// The debug switch is the core's: the core is always there (requiredAddons),
// and a second switch would be a second place for the two to disagree.
class OZG_Log
{
    // The warnings written since ResetWarned(): the ready line counts them as
    // `problems=`.
    private static int s_Warned;

    static void Info(string msg)
    {
        Print(OZG_Const.LOG_PREFIX + msg);
    }

    static void Warn(string msg)
    {
        s_Warned++;
        Print(OZG_Const.LOG_PREFIX + "WARNING: " + msg);
    }

    static void ResetWarned()
    {
        s_Warned = 0;
    }

    static int Warned()
    {
        return s_Warned;
    }

    static void Error(string msg)
    {
        Print(OZG_Const.LOG_PREFIX + "ERROR: " + msg);
    }

    static void Dbg(string msg)
    {
        if (!OZ_Log.IsDebug())
            return;
        Print(OZG_Const.LOG_PREFIX + "dbg: " + msg);
    }
}
```

```c
    // 0 for a two .. 12 for an ace; -1 for what is not a card.
    static int RankOf(string card)
    {
        if (card.Length() != 2)
            return -1;
        string ranks = RANKS;
        return ranks.IndexOf(card.Substring(0, 1));
    }

    // "s", "h", "d" or "c"; "" for what is not a card.
    static string SuitOf(string card)
    {
        if (card.Length() != 2)
            return "";
        string suits = SUITS;
        string suit = card.Substring(1, 1);
        if (suits.IndexOf(suit) < 0)
            return "";
        return suit;
    }

    static bool IsCard(string card)
    {
        if (RankOf(card) < 0)
            return false;
        return SuitOf(card) != "";
    }

    // The 52, in a fixed order: spades, hearts, diamonds, clubs, each from the
    // two up to the ace.
    static void Whole(array<string> into)
    {
        FromRank("2", into);
    }

    // The cards from this rank up, in the same order: "6" gives the 36.
    static void FromRank(string lowest, array<string> into)
    {
        string ranks = RANKS;
        string suits = SUITS;
        int first = ranks.IndexOf(lowest);
        if (first < 0)
            first = 0;
        for (int s = 0; s < suits.Length(); s++)
        {
            for (int r = first; r < ranks.Length(); r++)
                into.Insert(ranks.Substring(r, 1) + suits.Substring(s, 1));
        }
    }

    // "6s 7h Qd": for the log and the stand.
    static string Line(array<string> cards)
    {
        string text = "";
        for (int i = 0; i < cards.Count(); i++)
        {
            if (i > 0)
                text = text + " ";
            text = text + cards[i];
        }
        return text;
    }

    // The other way: cards parted by spaces or commas. What is not a card is
    // left out.
    static void Parse(string text, array<string> into)
    {
        string plain = text;
        plain.Replace(",", " ");
        array<string> parts = new array<string>();
        plain.Split(" ", parts);
        for (int i = 0; i < parts.Count(); i++)
        {
            if (IsCard(parts[i]))
                into.Insert(parts[i]);
        }
    }
}
```

```c
// one; a stand check hands in one that knows its answers, so that the order of
// the deck can be fixed.
class OZG_Random
{
    // A whole number from 0 up to, not including, n.
    int Below(int n)
    {
        if (n <= 1)
            return 0;
        return Math.RandomInt(0, n);
    }

    // Fisher-Yates over Below().
    void Shuffle(array<string> cards)
    {
        for (int i = cards.Count() - 1; i > 0; i--)
        {
            int j = Below(i + 1);
            cards.SwapItems(i, j);
        }
    }
}
```

```c
// The games this server can play. A mod registers a sample of its game when the
// mission starts; a session asks for a fresh one by id.
class OZG_Games
{
    private static ref map<string, ref OZG_Game> s_Samples = new map<string, ref OZG_Game>();
    // The ids in the order they were registered: a map keeps none.
    private static ref array<string> s_Order = new array<string>();

    static void Register(OZG_Game sample)
    {
        if (!sample)
            return;
        string id = sample.GameId();
        if (id == "")
        {
            OZG_Log.Warn("a game with no id was not registered");
            return;
        }
        if (s_Samples.Contains(id))
        {
            OZG_Log.Warn("the game '" + id + "' is registered twice; the first one stays");
            return;
        }
        s_Samples.Set(id, sample);
        s_Order.Insert(id);
    }

    // A new game of this kind, or null when nobody registered one.
    static OZG_Game Create(string id)
    {
        OZG_Game sample = Sample(id);
        if (!sample)
            return null;
        return sample.Fresh();
    }

    // The registered sample itself: for what the lobby asks.
    static OZG_Game Sample(string id)
    {
        OZG_Game sample;
        if (!s_Samples.Find(id, sample))
            return null;
        return sample;
    }

    static void Ids(array<string> into)
    {
        for (int i = 0; i < s_Order.Count(); i++)
            into.Insert(s_Order[i]);
    }

    static int Count()
    {
        return s_Order.Count();
    }

    static void Reset()
    {
        s_Samples.Clear();
        s_Order.Clear();
    }
}
```

```c
// Chance that does what it was told: the deck comes out in the order named.
class OZG_BenchFixed : OZG_Random
{
    protected ref array<string> m_Order;

    void OZG_BenchFixed(array<string> order)
    {
        m_Order = new array<string>();
        m_Order.Copy(order);
    }

    // The cards named come first, in the order named; the rest follow in the
    // order they had.
    override void Shuffle(array<string> cards)
    {
        array<string> rest = new array<string>();
        rest.Copy(cards);
        cards.Clear();
        int i;
        for (i = 0; i < m_Order.Count(); i++)
        {
            int at = rest.Find(m_Order[i]);
            if (at < 0)
                continue;
            cards.Insert(m_Order[i]);
            rest.RemoveOrdered(at);
        }
        for (i = 0; i < rest.Count(); i++)
            cards.Insert(rest[i]);
    }
}

class OZG_BenchSeeded : OZG_Random
{
    protected int m_Seed;

    void OZG_BenchSeeded(int seed)
    {
        m_Seed = seed % 65536;
        if (m_Seed < 0)

    // steps, and 75 * 65536 stays inside an int.
    override int Below(int n)
    {
        m_Seed = (m_Seed * 75 + 74) % 65537;
        if (n <= 1)
            return 0;
        return m_Seed % n;
    }
}

            array<string> order = new array<string>();
            OZG_Cards.Parse(deck, order);
            chance = new OZG_BenchFixed(order);
        }
        else if (seed == "0")
        {
            chance = new OZG_Random();
        }
        else
        {
            chance = new OZG_BenchSeeded(seed.ToInt());
        }

        // A refusal of the game is an answer, and the game on the bench stays.
        string refusal;
        if (!game.Begin(seats, options, chance, OZG_VerbOps.Arg(args, "hint", ""), refusal))
        {
            detail = "no " + refusal;
            return true;
        }
        s_Game = game;
        s_Absent.Clear();
        s_Saved = "";
        detail = game.Brief();
        return true;
    }

    // act seat=<n> move=<move>
    static bool OpAct(map<string, string> args, out string detail)
    {
        if (!HasGame(detail))
            return false;
        int seat = OZG_VerbOps.Arg(args, "seat", "0").ToInt();
        string move = OZG_VerbOps.Arg(args, "move", "");
        string refusal;
        if (!s_Game.Act(seat, move, refusal))
        {
            detail = "no " + refusal + " | " + s_Game.Brief();
            return true;
        }
        detail = "ok" + Skipped() + " | " + s_Game.Brief();
        return true;
    }

    // play moves=<seat> <move>; <seat> <move>; ..: several moves in one call.
    // The answer marks each `+`, or `-` and its refusal, then says the brief
    // after the last one.
    static bool OpPlay(map<string, string> args, out string detail)
    {
        if (!HasGame(detail))
            return false;
        string moves = OZG_VerbOps.Arg(args, "moves", "");
        array<string> steps = new array<string>();
        moves.Split(";", steps);
        string marks = "";
        int skipped = 0;
        for (int i = 0; i < steps.Count(); i++)
        {
            string step = steps[i].Trim();
            int gap = step.IndexOf(" ");
            if (gap <= 0)
            {
                detail = "play: '" + step + "' is not <seat> <move>";
                return false;
            }
            int seat = step.Substring(0, gap).ToInt();
            string move = step.Substring(gap + 1, step.Length() - gap - 1).Trim();
            string refusal;
            if (i > 0)
                marks = marks + " ";
            if (s_Game.Act(seat, move, refusal))
            {
                marks = marks + "+";
                skipped = skipped + s_Game.SkipAbsent(s_Absent);
            }
            else
            {
                marks = marks + "-" + refusal;
            }
        }
        if (skipped > 0)
            marks = marks + " skipped=" + skipped.ToString();
        detail = marks + " | " + s_Game.Brief();
        return true;
    }

    // outcome: what the game that ended tells the next deal.
    static bool OpOutcome(out string detail)
    {
        if (!HasGame(detail))
            return false;
        string outcome = s_Game.Outcome();
        if (outcome == "")
            outcome = "-";
        detail = "outcome: " + outcome;
        return true;
    }

    static bool OpBrief(out string detail)
    {
        if (!HasGame(detail))
            return false;
        detail = s_Game.Brief();
        return true;
    }

    // all: every hand, the table and the stock.
    static bool OpAll(out string detail)
    {
        if (!HasGame(detail))
            return false;
        detail = s_Game.Everything();
        return true;
    }

    // can seat=<n>: is the seat waited for, may it be passed over, and what may
    // it play now.
    static bool OpCan(map<string, string> args, out string detail)
    {
        if (!HasGame(detail))
            return false;
        int seat = OZG_VerbOps.Arg(args, "seat", "0").ToInt();
        array<string> can = new array<string>();
        s_Game.Moves(seat, can);
        detail = "seat " + seat.ToString() + " waits=" + YesNo(s_Game.Waits(seat));
        detail = detail + " skippable=" + YesNo(s_Game.Skippable(seat));
        detail = detail + " can:";
        for (int i = 0; i < can.Count(); i++)
            detail = detail + " " + can[i];
        if (can.Count() == 0)
            detail = detail + " -";
        return true;
    }

    // drop seat=<n>: the seat is out and its cards are discarded.
    static bool OpDrop(map<string, string> args, out string detail)
    {
        if (!HasGame(detail))
            return false;
        int seat = OZG_VerbOps.Arg(args, "seat", "0").ToInt();
        s_Game.DropSeat(seat);
        detail = "dropped " + seat.ToString() + Skipped() + " | " + s_Game.Brief();
        return true;
    }

    // away seats=<n,n,..>: the players of these seats are not present; with no
    // seats, everybody is back.
    static bool OpAway(map<string, string> args, out string detail)
    {
        if (!HasGame(detail))
            return false;
        s_Absent.Clear();
        OZG_VerbOps.Numbers(OZG_VerbOps.Arg(args, "seats", ""), s_Absent);
        detail = "away: " + OZG_VerbOps.NumbersLine(s_Absent) + Skipped() + " | " + s_Game.Brief();
        return true;
    }

    // view seat=<n>: the two halves as a client at that seat gets them, written
    // to VIEW_FILE one a line; the answer says how big they are.
    static bool OpView(map<string, string> args, out string detail)
    {
        if (!HasGame(detail))
            return false;
        int seat = OZG_VerbOps.Arg(args, "seat", "0").ToInt();
        string shared = s_Game.PublicView();
        string own = s_Game.SeatView(seat);

        OZ_Json.EnsureTree();
        FileHandle fh = OpenFile(VIEW_FILE, FileMode.WRITE);
        if (fh)
        {
            FPrintln(fh, shared);
            FPrintln(fh, own);
            CloseFile(fh);
        }
        detail = "view: public " + shared.Length().ToString() + " B, seat " + seat.ToString();
        detail = detail + " " + own.Length().ToString() + " B -> games_view.txt";
        return true;
    }

    // save: the whole state is kept for `load` and written to SAVE_FILE.
    static bool OpSave(out string detail)
    {
        if (!HasGame(detail))
            return false;
        s_Saved = s_Game.SaveState();

        OZ_Json.EnsureTree();
        FileHandle fh = OpenFile(SAVE_FILE, FileMode.WRITE);
        if (fh)
        {
            FPrintln(fh, s_Saved);
            CloseFile(fh);
        }
        string why;
        string sound = "yes";
        if (!s_Game.Sound(why))
            sound = "no (" + why + ")";
        detail = "saved " + s_Saved.Length().ToString() + " B sound=" + sound + " -> games_save.json";
        return true;
    }

    // load [swap=<text>><text>]: a fresh game of the same kind loads what
    // `save` kept. With swap=, one piece of that text is replaced first, to
    // see a save that does not add up refused.
    static bool OpLoad(map<string, string> args, out string detail)
    {
        if (!HasGame(detail))
            return false;
        if (s_Saved == "")
        {
            detail = "nothing is saved: save first";
            return false;
        }
        string text = s_Saved;
        string swap = OZG_VerbOps.Arg(args, "swap", "");
        if (swap != "")
        {
            int mark = swap.IndexOf(">");
            if (mark <= 0)
            {
                detail = "swap= is <text>><text>";
                return false;
            }
            string piece = swap.Substring(0, mark);
            string instead = swap.Substring(mark + 1, swap.Length() - mark - 1);
            text.Replace(piece, instead);
        }

        OZG_Game game = s_Game.Fresh();
        if (!game.LoadState(text))
        {
            detail = "not loaded, the game on the bench stays | " + s_Game.Brief();
            return true;
        }
        s_Game = game;
        detail = "loaded | " + s_Game.Brief();
        return true;
    }

    // ---- what the ops share ---------------------------------------------------

    // What the absent seats need not do is passed over, as a session does
    // after every change.
    static string Skipped()
    {
        int skipped = s_Game.SkipAbsent(s_Absent);
        if (skipped == 0)
            return "";
        return " skipped=" + skipped.ToString();
    }

    static string KnownGames()
    {
        array<string> ids = new array<string>();
        OZG_Games.Ids(ids);
        if (ids.Count() == 0)
            return "none";
        string text = "";
        for (int i = 0; i < ids.Count(); i++)
        {
            if (i > 0)
                text = text + ", ";
            text = text + ids[i];
        }
        return text;
    }

    static string YesNo(bool yes)
    {
        if (yes)
            return "yes";
        return "no";
    }

    // The first and the last card of a list.
    static string Ends(array<string> cards)
    {
        if (cards.Count() == 0)
            return "-";
        return cards[0] + ".." + cards[cards.Count() - 1];
    }

    // How many cards a list holds, when it holds exactly the cards of the
    // other; "lost" when it does not.
    static string Kept(array<string> cards, array<string> whole)
    {
        if (cards.Count() != whole.Count())
            return "lost";
        array<string> rest = new array<string>();
        rest.Copy(whole);
        for (int i = 0; i < cards.Count(); i++)
        {
            int at = rest.Find(cards[i]);
            if (at < 0)
                return "lost";
            rest.RemoveOrdered(at);
        }
        return cards.Count().ToString();
    }
}
```

```c
// Whole games played by chance, with the state checked after every move. The
// game itself is asked what may be played (Moves), so this finds: a move the
// game offers and then refuses, a seat waited for with no move, a game that
// waits for nobody, cards that go missing or double, a save that does not load
// back, and a game that never ends.
class OZG_Fuzz
{
    // More moves than any game of the kind takes.
    static const int MOVE_LIMIT = 3000;

    protected static int s_Moves;
    protected static int s_Longest;
    protected static int s_Drops;
    protected static int s_Skips;
    protected static int s_WithLoser;
    protected static int s_NoLoser;

    // fuzz game=<id> games=<n> players=<n; 0: by chance> opt=<id=value;..>
    //      seed=<n; 0: the real chance> drop=<per mille of moves>
    //      away=<per mille of moves>
    static bool Run(map<string, string> args, out string detail)
    {
        string id = OZG_VerbOps.Arg(args, "game", "durak");
        if (!OZG_Games.Sample(id))
        {
            detail = "no game '" + id + "' is registered; known: " + OZG_Bench.KnownGames();
            return false;
        }
        int games = OZG_VerbOps.Arg(args, "games", "20").ToInt();
        if (games < 1)
            games = 1;
        if (games > 500)
            games = 500;
        int players = OZG_VerbOps.Arg(args, "players", "0").ToInt();
        int seed = OZG_VerbOps.Arg(args, "seed", "1").ToInt();
        int dropRate = OZG_VerbOps.Arg(args, "drop", "0").ToInt();
        int awayRate = OZG_VerbOps.Arg(args, "away", "0").ToInt();
        map<string, string> options = new map<string, string>();
        OZG_VerbOps.Pairs(OZG_VerbOps.Arg(args, "opt", ""), options);

        s_Moves = 0;
        s_Longest = 0;
        s_Drops = 0;
        s_Skips = 0;
        s_WithLoser = 0;
        s_NoLoser = 0;

        // seed=0 is the real chance, the one the server hands to a game: its
        // numbers differ every time. Any other seed repeats itself.
        OZG_Random chance;
        if (seed == 0)
            chance = new OZG_Random();
        else
            chance = new OZG_BenchSeeded(seed);
        int started = TickCount(0);
        for (int g = 0; g < games; g++)
        {
            string defect = PlayOne(id, players, options, chance, dropRate, awayRate);
            if (defect != "")
            {
                detail = "fuzz: DEFECT in game " + g.ToString() + " of seed " + seed.ToString() + ": " + defect;
                return true;
            }
        }
        int ms = TickCount(started) / 10000;

        detail = "fuzz: " + games.ToString() + " games, " + s_Moves.ToString() + " moves";
        detail = detail + ", longest " + s_Longest.ToString();
        detail = detail + ", drops " + s_Drops.ToString() + ", skipped " + s_Skips.ToString();
        detail = detail + ", with a loser " + s_WithLoser.ToString() + ", without " + s_NoLoser.ToString();
        detail = detail + ", 0 defects, " + ms.ToString() + " ms";
        return true;
    }

    // One game from its deal to its end. Returns "" or what went wrong.
    protected static string PlayOne(string id, int players, map<string, string> options, OZG_Random chance, int dropRate, int awayRate)
    {
        OZG_Game game = OZG_Games.Create(id);
        int n = players;
        if (n <= 0)
            n = game.MinPlayers() + chance.Below(game.MaxPlayers() - game.MinPlayers() + 1);
        array<int> seats = new array<int>();
        int i;
        for (i = 0; i < n; i++)
            seats.Insert(i);

        string refusal;
        if (!game.Begin(seats, options, chance, "host=0", refusal))
            return "the deal for " + n.ToString() + " was refused with " + refusal;

        array<int> absent = new array<int>();
        array<int> movers = new array<int>();
        array<string> offered = new array<string>();
        array<string> can = new array<string>();
        string why;
        int moves = 0;
        int turns = 0;
        while (!game.IsOver())
        {
            turns++;
            if (turns > MOVE_LIMIT)
                return "the game does not end: " + game.Brief();
            if (!game.Sound(why))
                return "the state does not add up (" + why + "): " + game.Brief();

            // Who is waited for, and what everybody may play.
            movers.Clear();
            offered.Clear();
            int waited = 0;
            for (i = 0; i < n; i++)
            {
                can.Clear();
                game.Moves(i, can);
                if (game.Waits(i))
                {
                    waited++;
                    if (can.Count() == 0)
                        return "seat " + i.ToString() + " is waited for and has no move: " + game.Brief();
                }
                for (int m = 0; m < can.Count(); m++)
                {
                    movers.Insert(i);
                    offered.Insert(can[m]);
                }
            }
            if (waited == 0)
                return "the game waits for nobody: " + game.Brief();

            // Now and then a seat is dropped, or a player leaves or comes back.
            if (dropRate > 0 && chance.Below(1000) < dropRate)
            {
                game.DropSeat(chance.Below(n));
                s_Drops++;
                continue;
            }
            if (awayRate > 0 && chance.Below(1000) < awayRate)
            {
                absent.Clear();
                int who = chance.Below(n + 1);
                if (who < n)
                    absent.Insert(who);
            }

            int pick = chance.Below(offered.Count());
            string before = game.Brief();
            if (!game.Act(movers[pick], offered[pick], refusal))
            {
                string refused = "seat " + movers[pick].ToString() + " was offered " + offered[pick];
                return refused + " and refused with " + refusal + ": " + before;
            }
            s_Skips = s_Skips + game.SkipAbsent(absent);
            moves++;

            // Every tenth move the game is saved and loaded into a fresh one,
            // which must read the same and is played on.
            if (moves % 10 == 0)
            {
                string saved = game.SaveState();
                OZG_Game copy = game.Fresh();
                if (!copy.LoadState(saved))
                    return "a save did not load back: " + game.Brief();
                if (copy.SaveState() != saved)
                    return "a loaded save reads differently: " + game.Brief();
                game = copy;
            }
        }

        if (!game.Sound(why))
            return "the state does not add up at the end (" + why + "): " + game.Brief();
        s_Moves = s_Moves + moves;
        if (moves > s_Longest)
            s_Longest = moves;
        // An outcome names a seat, or -1 for nobody.
        string outcome = game.Outcome();
        if (outcome.IndexOf("=-1") >= 0)
            s_NoLoser++;
        else
            s_WithLoser++;
        return "";
    }
}
```

```c
        if (op == "drop")
            return OZG_Bench.OpDrop(args, detail);
        if (op == "away")
            return OZG_Bench.OpAway(args, detail);
        if (op == "view")
            return OZG_Bench.OpView(args, detail);
        if (op == "save")

    static string KnownOps()

        return "status, deck, games, begin, act, play, outcome, brief, all, can, drop, away, view, save, load, fuzz";
    }

    // ---- what the ops share ---------------------------------------------------

    static string Arg(map<string, string> args, string key, string fallback)
    {
        if (!args)
            return fallback;
        string v;
        if (args.Find(key, v))
            return v;
        return fallback;
    }

    // "0, 2,5" -> 0 2 5.
    static void Numbers(string text, array<int> into)
    {
        string plain = text;
        plain.Replace(" ", "");
        array<string> parts = new array<string>();
        plain.Split(",", parts);
        for (int i = 0; i < parts.Count(); i++)
            into.Insert(parts[i].ToInt());
    }

    static string NumbersLine(array<int> numbers)
    {
        if (numbers.Count() == 0)
            return "-";
        string text = "";
        for (int i = 0; i < numbers.Count(); i++)
        {
            if (i > 0)
                text = text + ",";
            text = text + numbers[i].ToString();
        }
        return text;
    }

    // "variant=perevodnoy;other=x" -> a map.
    static void Pairs(string text, map<string, string> into)
    {
        array<string> pairs = new array<string>();
        text.Split(";", pairs);
        for (int i = 0; i < pairs.Count(); i++)
        {
            string pair = pairs[i];
            int eq = pair.IndexOf("=");
            if (eq <= 0)
                continue;
            into.Set(pair.Substring(0, eq), pair.Substring(eq + 1, pair.Length() - eq - 1));
        }
    }
}
```

- [x] **Step 2: Write `scripts/3_Game/OpenZone_Games/OZG_Durak.c`**

How to read it: `Begin` deals and names the first opener; `Act` parses a move and hands it to one of five `Move...` methods, each of which either refuses with a key or changes the table; after every move that stood, `Settle` asks whether the bout can close, and `CloseBout` moves the cards, lets everyone draw, marks who is out and opens the next bout or ends the game. Everything below "the table, read" only looks.

```c
// Durak, podkidnoy and perevodnoy (design §8). The rules and nothing else: no
// world, no players, no network. A seat comes in as the session's number;
// inside, it is its index in the list of the seats dealt in.
//
// A bout: the opener lays a card; every seat but the defender may lay cards of
// ranks already on the table; the defender beats each, takes, or (perevodnoy)
// moves the attack on. The bout closes by itself once nothing more can come:
// Settle() is asked after every move.
class OZG_Durak : OZG_Game
{
    protected ref OZG_DurakState m_S;

    // ---- what the lobby asks -------------------------------------------------

    override string GameId()
    {
        return OZG_DurakConst.GAME_ID;
    }

    override string LabelKey()
    {
        return "STR_OZG_GAME_DURAK";
    }

    override int MinPlayers()
    {
        return 2;
    }

    override int MaxPlayers()
    {
        return 6;
    }

    override void CardsUsed(array<string> into)
    {
        OZG_Cards.FromRank(OZG_DurakConst.LOWEST, into);
    }

    override void OptionList(array<ref OZG_Option> into)
    {
        OZG_Option variant = new OZG_Option();
        variant.OptionId = OZG_DurakConst.OPT_VARIANT;
        variant.LabelKey = "STR_OZG_DURAK_VARIANT";
        variant.ValueIds.Insert(OZG_DurakConst.VARIANT_THROW);
        variant.ValueKeys.Insert("STR_OZG_DURAK_THROW");
        variant.ValueIds.Insert(OZG_DurakConst.VARIANT_TRANSFER);
        variant.ValueKeys.Insert("STR_OZG_DURAK_TRANSFER");
        variant.DefaultId = OZG_DurakConst.VARIANT_THROW;
        into.Insert(variant);
    }

    override OZG_Game Fresh()
    {
        return new OZG_Durak();
    }

    // ---- the deal (rules 1 and 2) --------------------------------------------

    override bool Begin(array<int> seats, map<string, string> options, OZG_Random chance, string hint, out string refusal)
    {
        refusal = "";
        int n = seats.Count();
        if (n < MinPlayers() || n > MaxPlayers())
        {
            refusal = OZG_Const.NO_PLAYERS;
            return false;
        }

        OZG_DurakState s = new OZG_DurakState();
        s.Version = OZG_DurakConst.VERSION;
        string variant = OZG_Game.OptionOf(options, OZG_DurakConst.OPT_VARIANT, OZG_DurakConst.VARIANT_THROW);
        if (variant == OZG_DurakConst.VARIANT_TRANSFER)
            s.Transfer = 1;

        array<string> deck = new array<string>();
        CardsUsed(deck);
        // A deal with no chance handed in takes the real one. Into a local: a
        // parameter is not a strong reference and cannot take `new`.
        OZG_Random dice = chance;
        if (!dice)
            dice = new OZG_Random();
        dice.Shuffle(deck);

        // Six to each seat, a seat at a time; what is left is the stock.
        int at = 0;
        for (int i = 0; i < n; i++)
        {
            OZG_DurakSeat seat = new OZG_DurakSeat();
            seat.SeatNo = seats[i];
            for (int k = 0; k < OZG_DurakConst.HAND; k++)
            {
                seat.Held.Insert(deck[at]);
                at++;
            }
            s.SeatList.Insert(seat);
        }
        while (at < deck.Count())
        {
            s.StockCards.Insert(deck[at]);
            at++;
        }

        // The trump is the last card of the deck: the bottom of the stock, face
        // up. Six seats take the whole deck, and then it is the last card
        // dealt: shown, and kept in that hand.
        s.TrumpCard = deck[deck.Count() - 1];
        s.FirstBout = 1;

        m_S = s;
        OpenBout(FirstOpener(hint));
        return true;
    }

    // Who lays the first card of the game (rule 2). After a game with a durak
    // the seat before him, so that he defends; otherwise the holder of the
    // lowest trump; with no trump dealt, the first seat after the host.
    protected int FirstOpener(string hint)
    {
        int n = m_S.SeatList.Count();
        int durak = OZG_Game.HintInt(hint, OZG_DurakConst.HINT_DURAK, -1);
        int durakAt = IndexOfSeat(durak);
        if (durakAt >= 0)
            return (durakAt + n - 1) % n;

        string trump = OZG_Cards.SuitOf(m_S.TrumpCard);
        int lowestAt = -1;
        int lowestRank = 99;
        for (int i = 0; i < n; i++)
        {
            array<string> held = m_S.SeatList[i].Held;
            for (int k = 0; k < held.Count(); k++)
            {
                if (OZG_Cards.SuitOf(held[k]) != trump)
                    continue;
                int rank = OZG_Cards.RankOf(held[k]);
                if (rank < lowestRank)
                {
                    lowestRank = rank;
                    lowestAt = i;
                }
            }
        }
        if (lowestAt >= 0)
            return lowestAt;

        int host = OZG_Game.HintInt(hint, OZG_Const.HINT_HOST, -1);
        for (int j = 0; j < n; j++)
        {
            if (m_S.SeatList[j].SeatNo > host)
                return j;
        }
        return 0;
    }

    // ---- a move --------------------------------------------------------------

    // On the wire (design §8): `a:<card>` attack or throw in, `d:<card>:<n>`
    // beat the n-th attack card (counted from 1), `t:<card>` move the attack
    // on, `take`, `pass`.
    override bool Act(int seat, string move, out string refusal)
    {
        refusal = "";
        if (!m_S || m_S.Ended == 1)
        {
            refusal = OZG_Const.NO_OVER;
            return false;
        }
        int i = IndexOfSeat(seat);
        if (i < 0 || m_S.SeatList[i].Gone != OZG_DurakConst.IN_PLAY)
        {
            refusal = OZG_Const.NO_SEAT;
            return false;
        }

        array<string> parts = new array<string>();
        move.Split(":", parts);
        string verb = "";
        if (parts.Count() > 0)
            verb = parts[0];

        bool done = false;
        if (verb == "a" && parts.Count() == 2)
            done = MoveAttack(i, parts[1], refusal);
        else if (verb == "d" && parts.Count() == 3)
            done = MoveDefend(i, parts[1], parts[2].ToInt(), refusal);
        else if (verb == "t" && parts.Count() == 2)
            done = MoveTransfer(i, parts[1], refusal);
        else if (verb == "take" && parts.Count() == 1)
            done = MoveTake(i, refusal);
        else if (verb == "pass" && parts.Count() == 1)
            done = MovePass(i, refusal);
        else
            refusal = OZG_Const.NO_MOVE;

        if (!done)
            return false;
        Settle();
        return true;
    }

    // a:<card> -- the opener's first card, or one more card beside the attack
    // (rules 3 and 4).
    protected bool MoveAttack(int i, string card, out string refusal)
    {
        if (i == m_S.Defender)
        {
            refusal = OZG_DurakConst.NO_DEFENDER;
            return false;
        }
        array<string> held = m_S.SeatList[i].Held;
        int at = held.Find(card);
        if (at < 0)
        {
            refusal = OZG_Const.NO_CARD;
            return false;
        }
        if (m_S.AttackCards.Count() == 0)
        {
            if (i != m_S.Opener)
            {
                refusal = OZG_DurakConst.NO_TURN;
                return false;
            }
        }
        else
        {
            if (m_S.AttackCards.Count() >= m_S.AttackLimit)
            {
                refusal = OZG_DurakConst.NO_LIMIT;
                return false;
            }
            if (!RankOnTable(OZG_Cards.RankOf(card)))
            {
                refusal = OZG_DurakConst.NO_RANK;
                return false;
            }
        }

        held.RemoveOrdered(at);
        m_S.AttackCards.Insert(card);
        m_S.DefenceCards.Insert("");
        ClearPassed();
        return true;
    }

    // d:<card>:<n> -- beat the n-th attack card (rule 5).
    protected bool MoveDefend(int i, string card, int nth, out string refusal)
    {
        if (i != m_S.Defender)
        {
            refusal = OZG_DurakConst.NO_NOT_DEFENDER;
            return false;
        }
        if (m_S.Taking == 1)
        {
            refusal = OZG_DurakConst.NO_TAKING;
            return false;
        }
        array<string> held = m_S.SeatList[i].Held;
        int at = held.Find(card);
        if (at < 0)
        {
            refusal = OZG_Const.NO_CARD;
            return false;
        }
        int target = nth - 1;
        if (target < 0 || target >= m_S.AttackCards.Count())
        {
            refusal = OZG_DurakConst.NO_TARGET;
            return false;
        }
        if (m_S.DefenceCards[target] != "")
        {
            refusal = OZG_DurakConst.NO_TARGET;
            return false;
        }
        if (!Beats(card, m_S.AttackCards[target]))
        {
            refusal = OZG_DurakConst.NO_BEAT;
            return false;
        }

        held.RemoveOrdered(at);
        m_S.DefenceCards[target] = card;
        ClearPassed();
        return true;
    }

    // t:<card> -- perevodnoy: a card of the attack's rank laid beside it, and
    // the attack moves on to the next seat in play (rule 7).
    protected bool MoveTransfer(int i, string card, out string refusal)
    {
        if (i != m_S.Defender)
        {
            refusal = OZG_DurakConst.NO_NOT_DEFENDER;
            return false;
        }
        if (!TransferOpen(refusal))
            return false;
        array<string> held = m_S.SeatList[i].Held;
        int at = held.Find(card);
        if (at < 0)
        {
            refusal = OZG_Const.NO_CARD;
            return false;
        }
        if (OZG_Cards.RankOf(card) != OZG_Cards.RankOf(m_S.AttackCards[0]))
        {
            refusal = OZG_DurakConst.NO_TRANSFER_RANK;
            return false;
        }

        held.RemoveOrdered(at);
        m_S.AttackCards.Insert(card);
        m_S.DefenceCards.Insert("");
        // The one who moved it on attacks now; the limit is counted anew.
        m_S.Defender = NextLive(i);
        m_S.AttackLimit = LimitFor(m_S.Defender);
        ClearPassed();
        return true;
    }

    // May the attack be moved on now, whatever the card? Says why not.
    protected bool TransferOpen(out string refusal)
    {
        refusal = "";
        if (m_S.Transfer != 1)
        {
            refusal = OZG_DurakConst.NO_TRANSFER_OFF;
            return false;
        }
        if (m_S.AttackCards.Count() == 0)
        {
            refusal = OZG_DurakConst.NO_EMPTY;
            return false;
        }
        if (m_S.Taking == 1 || BeatenCount() > 0)
        {
            refusal = OZG_DurakConst.NO_TRANSFER_LATE;
            return false;
        }
        // The next seat has to hold a card for every card that will lie there.
        int next = NextLive(m_S.Defender);
        if (next < 0)
        {
            refusal = OZG_DurakConst.NO_TRANSFER_FEW;
            return false;
        }
        if (m_S.SeatList[next].Held.Count() < m_S.AttackCards.Count() + 1)
        {
            refusal = OZG_DurakConst.NO_TRANSFER_FEW;
            return false;
        }
        return true;
    }

    // take -- the defender takes everything once nobody throws in any more.
    protected bool MoveTake(int i, out string refusal)
    {
        if (i != m_S.Defender)
        {
            refusal = OZG_DurakConst.NO_NOT_DEFENDER;
            return false;
        }
        if (m_S.AttackCards.Count() == 0)
        {
            refusal = OZG_DurakConst.NO_EMPTY;
            return false;
        }
        if (m_S.Taking == 1)
        {
            refusal = OZG_DurakConst.NO_TAKING;
            return false;
        }
        if (!HasUnbeaten())
        {
            refusal = OZG_DurakConst.NO_TAKE;
            return false;
        }

        m_S.Taking = 1;
        // The attackers are asked once more: they may add to what he takes.
        ClearPassed();
        return true;
    }

    // pass -- "nothing more from me", until a new card is laid.
    protected bool MovePass(int i, out string refusal)
    {
        if (i == m_S.Defender)
        {
            refusal = OZG_DurakConst.NO_DEFENDER;
            return false;
        }
        if (m_S.AttackCards.Count() == 0)
        {
            refusal = OZG_DurakConst.NO_EMPTY;
            return false;
        }
        if (m_S.SeatList[i].Passed == 1 || !CanThrow(i))
        {
            refusal = OZG_DurakConst.NO_PASS;
            return false;
        }

        m_S.SeatList[i].Passed = 1;
        return true;
    }

    // ---- the bout ------------------------------------------------------------

    // Starts a bout with this seat as the opener.
    protected void OpenBout(int opener)
    {
        m_S.Opener = opener;
        m_S.Defender = NextLive(opener);
        m_S.AttackCards.Clear();
        m_S.DefenceCards.Clear();
        m_S.Taking = 0;
        ClearPassed();
        m_S.AttackLimit = LimitFor(m_S.Defender);
    }

    // No more attack cards than the defender holds now, and no more than six;
    // in the first bout of a game, five (rule 4).
    protected int LimitFor(int defender)
    {
        int most = OZG_DurakConst.LIMIT;
        if (m_S.FirstBout == 1)
            most = OZG_DurakConst.LIMIT_FIRST;
        int held = m_S.SeatList[defender].Held.Count();
        if (held < most)
            return held;
        return most;
    }

    // After every move: closes the bout once everything is beaten, or the
    // defender takes, and every seat that could still throw in has passed
    // (rule 6). A seat with nothing to throw in is passed by itself.
    protected void Settle()
    {
        if (m_S.AttackCards.Count() == 0)
            return;
        if (m_S.Taking == 0 && HasUnbeaten())
            return;
        for (int i = 0; i < m_S.SeatList.Count(); i++)
        {
            if (m_S.SeatList[i].Passed == 0 && CanThrow(i))
                return;
        }
        CloseBout();
    }

    protected void CloseBout()
    {
        int defender = m_S.Defender;
        bool took = m_S.Taking == 1;
        int i;
        if (took)
        {
            array<string> held = m_S.SeatList[defender].Held;
            for (i = 0; i < m_S.AttackCards.Count(); i++)
            {
                held.Insert(m_S.AttackCards[i]);
                if (m_S.DefenceCards[i] != "")
                    held.Insert(m_S.DefenceCards[i]);
            }
        }
        else
        {
            for (i = 0; i < m_S.AttackCards.Count(); i++)
            {
                m_S.DiscardCards.Insert(m_S.AttackCards[i]);
                m_S.DiscardCards.Insert(m_S.DefenceCards[i]);
            }
        }
        m_S.AttackCards.Clear();
        m_S.DefenceCards.Clear();
        m_S.Taking = 0;
        m_S.FirstBout = 0;
        ClearPassed();

        DrawAll(m_S.Opener, defender);
        MarkOut();
        if (Finish(false))
            return;

        // A defender who beat everything attacks next; one who took is skipped
        // (rule 9).
        int opener = defender;
        if (took || !Live(defender))
            opener = NextLive(defender);
        OpenBout(opener);
    }

    // Everyone draws up to six while the stock lasts: from this seat around
    // the mat, the defender last (rule 8). With no defender (-1), simply
    // around the mat.
    protected void DrawAll(int from, int defender)
    {
        int n = m_S.SeatList.Count();
        for (int k = 0; k < n; k++)
        {
            int i = (from + k) % n;
            if (i == defender)
                continue;
            DrawUp(i);
        }
        if (defender >= 0)
            DrawUp(defender);
    }

    protected void DrawUp(int i)
    {
        OZG_DurakSeat seat = m_S.SeatList[i];
        if (seat.Gone != OZG_DurakConst.IN_PLAY)
            return;
        while (seat.Held.Count() < OZG_DurakConst.HAND && m_S.StockCards.Count() > 0)
        {
            seat.Held.Insert(m_S.StockCards[0]);
            m_S.StockCards.RemoveOrdered(0);
        }
    }

    // A seat with no cards once the stock is empty is out (rule 10).
    protected void MarkOut()
    {
        if (m_S.StockCards.Count() > 0)
            return;
        for (int i = 0; i < m_S.SeatList.Count(); i++)
        {
            OZG_DurakSeat seat = m_S.SeatList[i];
            if (seat.Gone == OZG_DurakConst.IN_PLAY && seat.Held.Count() == 0)
                seat.Gone = OZG_DurakConst.GONE_OUT;
        }
    }

    // Ends the game when fewer than two seats are in play: the last one with
    // cards is the durak, nobody left is a tie. A game that ends because a seat
    // was dropped has no durak (rule 11).
    protected bool Finish(bool afterDrop)
    {
        int inPlay = 0;
        int last = -1;
        for (int i = 0; i < m_S.SeatList.Count(); i++)
        {
            if (m_S.SeatList[i].Gone == OZG_DurakConst.IN_PLAY)
            {
                inPlay++;
                last = i;
            }
        }
        if (inPlay >= 2)
            return false;

        m_S.Ended = 1;
        m_S.DurakSeat = -1;
        m_S.Tie = 0;
        if (!afterDrop)
        {
            if (inPlay == 1)
                m_S.DurakSeat = m_S.SeatList[last].SeatNo;
            else
                m_S.Tie = 1;
        }
        return true;
    }

    // The seat is out in mid-game: its hand and whatever lies on the table go
    // to the discards and nobody takes; everyone draws; the first seat in play
    // after it attacks (rule 11).
    override void DropSeat(int seat)
    {
        if (!m_S || m_S.Ended == 1)
            return;
        int at = IndexOfSeat(seat);
        if (at < 0)
            return;
        OZG_DurakSeat dropped = m_S.SeatList[at];
        if (dropped.Gone != OZG_DurakConst.IN_PLAY)
            return;

        int i;
        for (i = 0; i < dropped.Held.Count(); i++)
            m_S.DiscardCards.Insert(dropped.Held[i]);
        dropped.Held.Clear();
        dropped.Gone = OZG_DurakConst.GONE_DROPPED;

        for (i = 0; i < m_S.AttackCards.Count(); i++)
        {
            m_S.DiscardCards.Insert(m_S.AttackCards[i]);
            if (m_S.DefenceCards[i] != "")
                m_S.DiscardCards.Insert(m_S.DefenceCards[i]);
        }
        m_S.AttackCards.Clear();
        m_S.DefenceCards.Clear();
        m_S.Taking = 0;
        ClearPassed();

        DrawAll((at + 1) % m_S.SeatList.Count(), -1);
        MarkOut();
        if (Finish(true))
            return;
        OpenBout(NextLive(at));
    }

    // ---- who is waited for ---------------------------------------------------

    // The game stands still for: the opener while the table is empty; the
    // defender while a card lies unbeaten and he has not said "take"; and, once
    // the bout could close, every seat that may still throw in and has not
    // passed.
    override bool Waits(int seat)
    {
        if (!m_S || m_S.Ended == 1)
            return false;
        int i = IndexOfSeat(seat);
        if (i < 0 || m_S.SeatList[i].Gone != OZG_DurakConst.IN_PLAY)
            return false;
        if (m_S.AttackCards.Count() == 0)
            return i == m_S.Opener;
        if (i == m_S.Defender)
        {
            if (m_S.Taking == 1)
                return false;
            return HasUnbeaten();
        }
        if (m_S.Taking == 0 && HasUnbeaten())
            return false;
        if (m_S.SeatList[i].Passed == 1)
            return false;
        return CanThrow(i);
    }

    // Throwing in is a move a seat need not make; the opener's first card and
    // the defender's answer are not.
    override bool Skippable(int seat)
    {
        if (!Waits(seat))
            return false;
        if (m_S.AttackCards.Count() == 0)
            return false;
        return IndexOfSeat(seat) != m_S.Defender;
    }

    override void SkipSeat(int seat)
    {
        if (!Skippable(seat))
            return;
        string refusal;
        Act(seat, "pass", refusal);
    }

    // What this seat may do now. The window lights these; a check plays them.
    override void Moves(int seat, array<string> into)
    {
        if (!m_S || m_S.Ended == 1)
            return;
        int i = IndexOfSeat(seat);
        if (i < 0 || m_S.SeatList[i].Gone != OZG_DurakConst.IN_PLAY)
            return;
        array<string> held = m_S.SeatList[i].Held;
        int k;

        if (m_S.AttackCards.Count() == 0)
        {
            if (i != m_S.Opener)
                return;
            for (k = 0; k < held.Count(); k++)
                into.Insert("a:" + held[k]);
            return;
        }

        if (i == m_S.Defender)
        {
            if (m_S.Taking == 1)
                return;
            for (int a = 0; a < m_S.AttackCards.Count(); a++)
            {
                if (m_S.DefenceCards[a] != "")
                    continue;
                int nth = a + 1;
                for (k = 0; k < held.Count(); k++)
                {
                    if (Beats(held[k], m_S.AttackCards[a]))
                        into.Insert("d:" + held[k] + ":" + nth.ToString());
                }
            }
            string why;
            if (TransferOpen(why))
            {
                int rank = OZG_Cards.RankOf(m_S.AttackCards[0]);
                for (k = 0; k < held.Count(); k++)
                {
                    if (OZG_Cards.RankOf(held[k]) == rank)
                        into.Insert("t:" + held[k]);
                }
            }
            if (HasUnbeaten())
                into.Insert("take");
            return;
        }

        if (m_S.AttackCards.Count() < m_S.AttackLimit)
        {
            for (k = 0; k < held.Count(); k++)
            {
                if (RankOnTable(OZG_Cards.RankOf(held[k])))
                    into.Insert("a:" + held[k]);
            }
        }
        if (m_S.SeatList[i].Passed == 0 && CanThrow(i))
            into.Insert("pass");
    }

    // ---- the table, read -----------------------------------------------------

    protected int IndexOfSeat(int seat)
    {
        if (!m_S)
            return -1;
        for (int i = 0; i < m_S.SeatList.Count(); i++)
        {
            if (m_S.SeatList[i].SeatNo == seat)
                return i;
        }
        return -1;
    }

    protected int SeatNoAt(int i)
    {
        if (i < 0 || i >= m_S.SeatList.Count())
            return -1;
        return m_S.SeatList[i].SeatNo;
    }

    // In play, with something to play or to draw: a seat that has shed its
    // last card after the stock ran out is not, even before the bout closes.
    protected bool Live(int i)
    {
        OZG_DurakSeat seat = m_S.SeatList[i];
        if (seat.Gone != OZG_DurakConst.IN_PLAY)
            return false;
        if (seat.Held.Count() > 0)
            return true;
        return m_S.StockCards.Count() > 0;
    }

    // The next such seat after this one, around the mat; -1 when there is no
    // other.
    protected int NextLive(int from)
    {
        int n = m_S.SeatList.Count();
        for (int k = 1; k < n; k++)
        {
            int i = (from + k) % n;
            if (Live(i))
                return i;
        }
        return -1;
    }

    protected void ClearPassed()
    {
        for (int i = 0; i < m_S.SeatList.Count(); i++)
            m_S.SeatList[i].Passed = 0;
    }

    protected bool HasUnbeaten()
    {
        for (int i = 0; i < m_S.DefenceCards.Count(); i++)
        {
            if (m_S.DefenceCards[i] == "")
                return true;
        }
        return false;
    }

    protected int BeatenCount()
    {
        int beaten = 0;
        for (int i = 0; i < m_S.DefenceCards.Count(); i++)
        {
            if (m_S.DefenceCards[i] != "")
                beaten++;
        }
        return beaten;
    }

    protected bool RankOnTable(int rank)
    {
        int i;
        for (i = 0; i < m_S.AttackCards.Count(); i++)
        {
            if (OZG_Cards.RankOf(m_S.AttackCards[i]) == rank)
                return true;
        }
        for (i = 0; i < m_S.DefenceCards.Count(); i++)
        {
            if (m_S.DefenceCards[i] == "")
                continue;
            if (OZG_Cards.RankOf(m_S.DefenceCards[i]) == rank)
                return true;
        }
        return false;
    }

    // May this seat lay one more card beside the attack now?
    protected bool CanThrow(int i)
    {
        if (i == m_S.Defender)
            return false;
        if (m_S.SeatList[i].Gone != OZG_DurakConst.IN_PLAY)
            return false;
        if (m_S.AttackCards.Count() == 0)
            return false;
        if (m_S.AttackCards.Count() >= m_S.AttackLimit)
            return false;
        array<string> held = m_S.SeatList[i].Held;
        for (int k = 0; k < held.Count(); k++)
        {
            if (RankOnTable(OZG_Cards.RankOf(held[k])))
                return true;
        }
        return false;
    }

    // A higher card of the same suit, or a trump over what is not one (rule 5).
    protected bool Beats(string card, string target)
    {
        string suit = OZG_Cards.SuitOf(card);
        if (suit == OZG_Cards.SuitOf(target))
            return OZG_Cards.RankOf(card) > OZG_Cards.RankOf(target);
        return suit == OZG_Cards.SuitOf(m_S.TrumpCard);
    }

    protected string VariantId()
    {
        if (m_S && m_S.Transfer == 1)
            return OZG_DurakConst.VARIANT_TRANSFER;
        return OZG_DurakConst.VARIANT_THROW;
    }

    // ---- the end, the views, the save ----------------------------------------

    override bool IsOver()
    {
        if (!m_S)
            return true;
        return m_S.Ended == 1;
    }

    override string Outcome()
    {
        if (!m_S || m_S.Ended == 0)
            return "";
        return OZG_DurakConst.HINT_DURAK + "=" + m_S.DurakSeat.ToString();
    }

    override string PublicView()
    {
        if (!m_S)
            return "{}";
        OZG_DurakPublic v = new OZG_DurakPublic();
        v.GameId = OZG_DurakConst.GAME_ID;
        v.VariantId = VariantId();
        v.TrumpCard = m_S.TrumpCard;
        v.StockCount = m_S.StockCards.Count();
        v.DiscardCount = m_S.DiscardCards.Count();
        v.AttackCards.Copy(m_S.AttackCards);
        v.DefenceCards.Copy(m_S.DefenceCards);
        v.OpenerSeat = SeatNoAt(m_S.Opener);
        v.DefenderSeat = SeatNoAt(m_S.Defender);
        v.AttackLimit = m_S.AttackLimit;
        v.Taking = m_S.Taking;
        v.Ended = m_S.Ended;
        v.DurakSeat = m_S.DurakSeat;
        v.Tie = m_S.Tie;
        for (int i = 0; i < m_S.SeatList.Count(); i++)
        {
            OZG_DurakSeat seat = m_S.SeatList[i];
            OZG_DurakSeatPublic shown = new OZG_DurakSeatPublic();
            shown.SeatNo = seat.SeatNo;
            shown.CardCount = seat.Held.Count();
            shown.Gone = seat.Gone;
            shown.Passed = seat.Passed;
            v.SeatList.Insert(shown);
            if (Waits(seat.SeatNo))
                v.Awaited.Insert(seat.SeatNo);
        }
        string text;
        string err;
        JsonFileLoader<OZG_DurakPublic>.MakeData(v, text, err, false);
        return text;
    }

    override string SeatView(int seat)
    {
        OZG_DurakPrivate v = new OZG_DurakPrivate();
        int i = IndexOfSeat(seat);
        if (i >= 0)
        {
            v.Held.Copy(m_S.SeatList[i].Held);
            Moves(seat, v.CanPlay);
        }
        string text;
        string err;
        JsonFileLoader<OZG_DurakPrivate>.MakeData(v, text, err, false);
        return text;
    }

    override string SaveState()
    {
        if (!m_S)
            return "";
        string text;
        string err;
        JsonFileLoader<OZG_DurakState>.MakeData(m_S, text, err, false);
        return text;
    }

    override bool LoadState(string data)
    {
        OZG_DurakState s = new OZG_DurakState();
        string err;
        if (!JsonFileLoader<OZG_DurakState>.LoadData(data, s, err))
            return false;
        if (!s || s.Version != OZG_DurakConst.VERSION)
            return false;
        if (!s.SeatList || !s.StockCards || !s.DiscardCards)
            return false;
        if (!s.AttackCards || !s.DefenceCards)
            return false;
        for (int i = 0; i < s.SeatList.Count(); i++)
        {
            if (!s.SeatList[i] || !s.SeatList[i].Held)
                return false;
        }

        OZG_DurakState before = m_S;
        m_S = s;
        string why;
        if (!Sound(why))
        {
            m_S = before;
            return false;
        }
        return true;
    }

    // Every one of the 36 exactly once, between the hands, the stock, the
    // table and the discards; and the few numbers in their ranges.
    override bool Sound(out string why)
    {
        why = "";
        if (!m_S)
        {
            why = "no deal";
            return false;
        }
        int n = m_S.SeatList.Count();
        if (n < MinPlayers() || n > MaxPlayers())
        {
            why = "seats: " + n.ToString();
            return false;
        }
        if (m_S.DefenceCards.Count() != m_S.AttackCards.Count())
        {
            why = "the table does not pair up";
            return false;
        }
        if (m_S.Opener < 0 || m_S.Opener >= n || m_S.Defender < 0 || m_S.Defender >= n)
        {
            why = "the opener or the defender is no seat";
            return false;
        }
        if (!OZG_Cards.IsCard(m_S.TrumpCard))
        {
            why = "the trump is no card";
            return false;
        }

        array<string> have = new array<string>();
        int i;
        int k;
        for (i = 0; i < n; i++)
        {
            array<string> held = m_S.SeatList[i].Held;
            for (k = 0; k < held.Count(); k++)
                have.Insert(held[k]);
        }
        for (i = 0; i < m_S.StockCards.Count(); i++)
            have.Insert(m_S.StockCards[i]);
        for (i = 0; i < m_S.DiscardCards.Count(); i++)
            have.Insert(m_S.DiscardCards[i]);
        for (i = 0; i < m_S.AttackCards.Count(); i++)
        {
            have.Insert(m_S.AttackCards[i]);
            if (m_S.DefenceCards[i] != "")
                have.Insert(m_S.DefenceCards[i]);
        }

        array<string> want = new array<string>();
        CardsUsed(want);
        if (have.Count() != want.Count())
        {
            why = "cards: " + have.Count().ToString() + " of " + want.Count().ToString();
            return false;
        }
        for (i = 0; i < have.Count(); i++)
        {
            int at = want.Find(have[i]);
            if (at < 0)
            {
                why = "the card " + have[i] + " is there twice, or is not of this game";
                return false;
            }
            want.RemoveOrdered(at);
        }
        return true;
    }

    // One line: `durak <variant> trump= stock= dis= table= op= def= lim= take=
    // first= hands= waits=`. A hand is `<seat>:<cards>` with `x` for a seat
    // that is out, `d` for a dropped one and `p` for one that passed.
    override string Brief()
    {
        if (!m_S)
            return "durak: no deal";
        string text = "durak " + VariantId();
        if (m_S.Ended == 1)
            text = text + " over " + EndWord();
        text = text + " trump=" + m_S.TrumpCard;
        text = text + " stock=" + m_S.StockCards.Count().ToString();
        text = text + " dis=" + m_S.DiscardCards.Count().ToString();
        if (m_S.Ended == 0)
        {
            text = text + " table=" + TableLine();
            text = text + " op=" + SeatNoAt(m_S.Opener).ToString();
            text = text + " def=" + SeatNoAt(m_S.Defender).ToString();
            text = text + " lim=" + m_S.AttackLimit.ToString();
            text = text + " take=" + m_S.Taking.ToString();
            text = text + " first=" + m_S.FirstBout.ToString();
        }
        text = text + " hands=" + HandsLine();
        if (m_S.Ended == 0)
            text = text + " waits=" + WaitsLine();
        return text;
    }

    protected string EndWord()
    {
        if (m_S.DurakSeat >= 0)
            return "durak=" + m_S.DurakSeat.ToString();
        if (m_S.Tie == 1)
            return "tie";
        return "nodurak";
    }

    protected string TableLine()
    {
        if (m_S.AttackCards.Count() == 0)
            return "-";
        string text = "";
        for (int i = 0; i < m_S.AttackCards.Count(); i++)
        {
            if (i > 0)
                text = text + ",";
            string beat = m_S.DefenceCards[i];
            if (beat == "")
                beat = "-";
            text = text + m_S.AttackCards[i] + "/" + beat;
        }
        return text;
    }

    protected string HandsLine()
    {
        string text = "";
        for (int i = 0; i < m_S.SeatList.Count(); i++)
        {
            OZG_DurakSeat seat = m_S.SeatList[i];
            if (i > 0)
                text = text + ",";
            text = text + seat.SeatNo.ToString() + ":" + seat.Held.Count().ToString();
            if (seat.Gone == OZG_DurakConst.GONE_OUT)
                text = text + "x";
            if (seat.Gone == OZG_DurakConst.GONE_DROPPED)
                text = text + "d";
            if (seat.Passed == 1)
                text = text + "p";
        }
        return text;
    }

    protected string WaitsLine()
    {
        string text = "";
        for (int i = 0; i < m_S.SeatList.Count(); i++)
        {
            int seat = m_S.SeatList[i].SeatNo;
            if (!Waits(seat))
                continue;
            if (text != "")
                text = text + ",";
            text = text + seat.ToString();
        }
        if (text == "")
            return "-";
        return text;
    }

    // Every hand, the table and the stock, in full.
    override string Everything()
    {
        if (!m_S)
            return "durak: no deal";
        string text = "";
        for (int i = 0; i < m_S.SeatList.Count(); i++)
        {
            OZG_DurakSeat seat = m_S.SeatList[i];
            text = text + seat.SeatNo.ToString() + "[" + OZG_Cards.Line(seat.Held) + "] ";
        }
        text = text + "table[" + TableLine() + "] ";
        text = text + "stock[" + OZG_Cards.Line(m_S.StockCards) + "]";
        return text;
    }
}
```

### Task 6: Games played by chance, and the client's compile

- Produces: the second half of the phase's check. The scripted games show that the rules are the right ones; these show that no sequence of moves the game itself offers breaks it.

What a fuzz run does: it deals, and until the game ends it asks every seat what it may play (`Moves`), plays one of all those moves by chance, and after it checks that every one of the 36 cards is there exactly once (`Sound`), that somebody is waited for, and that whoever is waited for has a move. Every tenth move the game is saved, loaded into a fresh one that must read the same, and played on in that one. `drop=` drops a seat by chance that many times in a thousand moves; `away=` makes a player leave or come back as often, and what the absent need not do is passed over. A seeded run repeats itself: the same numbers every time. `seed=0` is the real chance and repeats nothing.

No code in this task.
